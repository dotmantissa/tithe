# How Tithe reaches a decision

A creator registers a public HTTPS artifact, its SHA256 hash, public terms and a price schedule. Validators fetch the original bytes and confirm the hash. Each change to terms creates an immutable version with its effective timestamp. Registration is a declaration of rights, not a finding of ownership.

An authenticated lab describes its use and deposits the exact published price. The desk reads the registry, snapshots that version and asks independently working validators to compare the intended use with those terms. An approved request becomes a licence record. A refused request credits the fee back to the requester. Credits are withdrawn through finalized value transfers.

A creator opens a dispute against a named respondent, commits the output hash, identifies the time of use and posts a bond. The respondent deposits an equal bond and may provide its published policy URL and a licence ID. The court checks that any licence belongs to that respondent and predates use. Validators fetch and hash both artifacts, read the historical terms and independently classify the use. Text embeddings supply a numeric comparison anchor. For images, the panel reads the images and embeds independently written descriptions; the score is descriptive, not a pixel distance.

Rulings agree exactly on USE, NO_USE or DERIVATIVE_WITHIN_TERMS, the numbered clause and the damages band. Embedding distance agrees within five percent with a small absolute floor near zero. Explanations may differ. A bounded damages award is paid from the posted respondent bond; this protocol cannot seize other assets. Network consensus appeals use GenLayer's native appeal mechanism and fresh validators. Application settlement waits beyond the configured appeal window and uses finalized transfers. The docket preserves evidence commitments, terms version, explanation and payout.

Next.js serves the interface and API. Privy verifies email identities. The server derives a distinct managed Studio account for each identity from a private HMAC master key. This is a custodial convenience service: preserve and back up the key, since losing it loses account access. Users see the fee and consent to the action; signing and network details remain backstage. The deployment wallet never signs user actions. Studio is a development network with test funds, not a production payment rail.

Neon stores a rebuildable search index, API key hashes, idempotency records and operation ownership. The chain is authoritative. The API returns operation IDs immediately and checks execution results before indexing confirmed records. API keys authorize the same account as their email owner. The MCP endpoint offers search, registration, licensing and docket tools through authenticated JSON RPC.

This is private licensing and arbitration. It is not a legal court judgment and does not guarantee a legal safe harbour. Version one accepts text and still images. Audio and video are refused.
